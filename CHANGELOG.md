# Changelog

## v1.0.0

Primeira versão pública do NotchHub.

### Música

- Integração com Spotify e Apple Music
- Exibição de título, artista, álbum e capa
- Play/Pause
- Música anterior e próxima
- Controle de progresso
- Controle de volume
- Estado quando nenhuma música está tocando

### Sistema

- Uso de CPU
- Uso de memória
- Bateria
- Informações de energia e sistema

### Calendário

- Integração com EventKit
- Eventos reais do Calendário do macOS
- Suporte a fontes Google, iCloud, Microsoft e outras
- Seleção persistente de calendários

### Ações

- Finder
- Downloads
- Ajustes do Sistema
- Monitor de Atividade
- Calendário
- Copiar música atual

### Interface

- Interface integrada à notch
- Expansão e retração automáticas
- Suporte a múltiplos monitores
- Temas Automático, Claro e Escuro
- Configurações próprias
- Inicialização automática com o macOS
- Identidade visual e ícone próprios

### Compatibilidade

- Universal Binary
- arm64
- x86_64
- macOS 26.5+
